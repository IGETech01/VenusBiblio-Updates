# Atualizar versões antigas do VenusBiblio

A versão recomendada para Windows está sempre em **[Releases → Última versão estável](https://github.com/IGETech01/VenusBiblio-Updates/releases/latest)**.

## Minha versão não tem atualização automática

Algumas versões antigas, como a linha **v0.12.x**, não possuem o atualizador integrado ao GitHub. Para atualizar, é necessário baixar e executar o instalador mais recente.

## Passos para atualizar manualmente

1. Faça backup dos seus livros, contas e preferências. Anote o local onde a versão antiga armazena seus dados.
2. Feche o VenusBiblio.
3. Baixe o instalador Windows pelo [link oficial](https://github.com/IGETech01/VenusBiblio-Updates/releases/latest).
4. Execute o instalador e confira qualquer opção de pasta ou de migração apresentada.
5. Abra o VenusBiblio e confirme a versão, o acervo e as preferências.

**Se os seus livros ou dados não aparecerem, preserve o backup.** Não apague pastas antigas antes de conferir onde os dados foram armazenados.

## Observações

Instaladores de versões antigas devem ser obtidos somente pelos canais oficiais. Os Releases Windows incluem manifesto assinado para conferência de integridade; isso não substitui um certificado Authenticode.

Ainda não há aplicativo Android oficial.
