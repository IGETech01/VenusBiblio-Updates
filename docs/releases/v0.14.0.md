# VenusBiblio by IGETech v0.14.0

**Versão anterior para Windows | 2 de novembro de 2026**

A v0.14.0 introduziu a distribuição estável com verificação de atualizações pelo GitHub.

## Recursos

- Biblioteca offline para **PDF, EPUB, mangás e HQs (CBZ)**.
- Interface escura com detalhes roxos e opções de personalização.
- **Workshop Cliente** para acesso aos recursos disponíveis.
- Atualizador integrado com verificação de integridade dos arquivos.
- Melhorias na organização e na preservação de dados de leitura.

## Download

Esta versão foi substituída pela **[v0.14.1](https://github.com/IGETech01/VenusBiblio-Updates/releases/tag/v0.14.1)**. Para uma instalação nova, utilize a [versão mais recente](https://github.com/IGETech01/VenusBiblio-Updates/releases/latest).

Se você já utiliza a v0.14.0, abra **Atualizações → Verificar atualizações**. Em caso de falha, baixe o instalador oficial mais recente e faça backup dos seus dados antes de instalar.

O Release histórico contém o instalador Windows e o manifesto assinado para atualizações.
