# VenusBiblio by IGETech v0.14.0

**Lançamento estável para Windows | 2 de novembro de 2026**

Esta versão reúne as melhorias das candidatas RC2/RC3, com o instalador completo para Windows e o fluxo de atualizações IGETech integrado ao GitHub.

### Destaques

- Interface refinada com identidade visual escura e roxa, opções de temas e ajustes de usabilidade.
- Biblioteca digital para leitura offline de **PDF, EPUB, mangás e HQs (CBZ)**.
- **Workshop Cliente** para acesso aos conteúdos disponíveis; ferramentas administrativas continuam restritas.
- Atualizador integrado com verificação de manifesto **Ed25519**, tamanho e **SHA-256**, com etapas de download, instalação e recuperação.
- Diagnóstico da comunicação com o GitHub, indicação de progresso e opção de cancelamento durante o download.
- Melhorias de estabilidade, preservação de dados de leitura e separação dos dados do usuário dos arquivos do aplicativo.

### Instalação e atualização

Baixe o `VenusBiblio_Setup_0.14.0.exe` deste Release. Para instalações anteriores, use a opção **Atualizações** do aplicativo se ela detectar esta versão; caso contrário, utilize o instalador oficial. Feche o aplicativo e mantenha uma cópia de segurança dos seus dados antes de atualizar.

**Arquivos do Release:** `manifest.json` (assinado pela IGETech) e `VenusBiblio_Setup_0.14.0.exe`.

### Validação

- Compilação do instalador Windows concluída.
- **307 testes automatizados** informados como aprovados durante a preparação da candidata e **6 verificações visuais** concluídas pelo responsável no Windows.
- Verificação de manifesto, tamanho e SHA-256 após download do rascunho do GitHub aprovada.
- Workflow [Validar integridade dos Releases](https://github.com/IGETech01/VenusBiblio-Updates/actions/workflows/validar-release.yml) concluído com sucesso na publicação.

**Limites:** os testes não equivalem a uma garantia de compatibilidade com todos os computadores. Versão Android ainda não disponível. O código-fonte privado, credenciais, contas e ferramentas exclusivas da IGETech não fazem parte dos assets públicos.
