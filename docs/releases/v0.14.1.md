# VenusBiblio by IGETech v0.14.1

**Lançamento estável Windows | Publicado em 2 de novembro de 2026**

A versão 0.14.1 traz otimizações de desempenho, correções e refinamentos discretos na interface do VenusBiblio, mantendo a identidade visual e a disposição geral das telas da v0.14.0.

## Novidades

- **Desempenho:** carregamento e dimensionamento mais eficientes de capas, limite para o cache de imagens e menos processamento repetido na tabela.
- **Organização:** otimizações na detecção de arquivos duplicados durante importações em lote.
- **Interface gráfica:** melhorias discretas nos campos de busca, comandos de limpar e estados de interação, sem reorganizar as telas.
- **Correções:** revisão de textos herdados de versões candidatas e ajustes para compatibilidade dos testes no Windows.
- **Preparação para Android:** base técnica inicial para selecionar caminhos de dados e separar comportamentos dependentes de plataforma. **Esta versão é exclusiva para Windows; não existe APK oficial.**

## Validações e segurança

- Hotfix aplicado no projeto de desenvolvimento, com testes aprovados e backup.
- **325 testes automatizados** aprovados durante o desenvolvimento; a execução no Windows informou **2 testes pulados**.
- Compilação do executável e do instalador Windows concluída.
- Abertura do executável e verificações funcionais no Windows aprovadas pelo responsável.
- Arquivos baixados do rascunho do GitHub passaram na validação de **assinatura Ed25519, SHA-256, tamanho e estrutura PE**.
- O workflow [Validar integridade dos Releases](https://github.com/IGETech01/VenusBiblio-Updates/actions/runs/41521055489) terminou com **sucesso** após a publicação.

**Pendente de confirmação em uso real:** o fluxo completo de atualização automática da v0.14.0 para a v0.14.1 pelo botão da interface. A verificação de assinatura e integridade não substitui esse teste funcional.

## Download e atualização

Este Release contém os dois arquivos oficiais:

- `VenusBiblio_Setup_0.14.1.exe`: instalador Windows.
- `manifest.json`: manifesto assinado para o atualizador integrado.

Se você já usa uma versão anterior, abra **Atualizações → Verificar atualizações**. Se a atualização não for oferecida, baixe o instalador diretamente [neste Release](https://github.com/IGETech01/VenusBiblio-Updates/releases/tag/v0.14.1).

Feche o aplicativo antes da instalação e mantenha backup dos seus dados. A assinatura do manifesto Ed25519 autentica a distribuição IGETech, mas não equivale à assinatura Authenticode do Windows.

O Release não inclui código-fonte privado, chaves secretas, contas ou bibliotecas pessoais.
