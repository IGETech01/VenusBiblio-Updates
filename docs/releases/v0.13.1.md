# VenusBiblio v0.13.1 | Pré-lançamento técnico

**Release de laboratório, publicado em 2 de novembro de 2026. NÃO instalar em produção.**

Este pré-lançamento foi criado exclusivamente para validar o mecanismo de atualização assinada. Não é uma nova versão funcional do VenusBiblio e não inclui o aplicativo completo.

### Conteúdo

- `manifest-source.json`: manifesto de atualização assinado com Ed25519.
- `VenusBiblio_Source_0.13.1.zip`: ZIP sintético contendo somente `app/versao.py`.

### Testes realizados

O ensaio em uma pasta temporária descartável concluiu **5/5 verificações**:
1. Download real dos assets pelo GitHub, com conferência dos hashes.
2. Validação de assinatura Ed25519, SHA-256 e tamanho.
3. Rejeição de manifesto adulterado.
4. Aplicação da atualização isolada com preservação de dados.
5. Reversão para a versão anterior, mantendo os dados de teste.

O teste não validou o botão de atualização da interface nem a rota `/releases/latest`. Por ser pré-lançamento, esta versão não deve ser promovida a estável.

**Não executar o ZIP na instalação principal; não usar este Release como instalador Windows.**
