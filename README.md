## Principais recursos

- Leitura de **PDF, EPUB, mangás e histórias em quadrinhos (CBZ)**.
- Biblioteca offline com capas, organização e pesquisa.
- **AuroraUI 1.3.0:** 14 temas, interface refinada e preferências de leitura.
- **Workshop Cliente** com catálogo público pelo GitHub (coleções disponíveis quando publicadas).
- **Atualizador integrado** nas versões compatíveis, com verificação de segurança dos arquivos oficiais.

## Como instalar ou atualizar

1. Salve uma cópia de segurança dos seus livros e dados.
2. Feche o VenusBiblio.
3. Baixe o instalador da [versão estável mais recente](https://github.com/IGETech01/VenusBiblio-Updates/releases/latest) e execute-o.
4. Abra o aplicativo e confira seu acervo e suas preferências.

**Já usa uma versão com atualizador integrado?** Acesse **Atualizações → Verificar atualizações**. Se houver erro ou sua versão não tiver esse recurso, utilize o instalador oficial.

**Versões antigas, incluindo a linha v0.12.x, não possuem atualização integrada pelo GitHub.** Para elas, a atualização é manual. Consulte o [guia de migração](docs/MIGRACAO_VERSOES_ANTIGAS.md).
