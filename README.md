# VenusBiblio by IGETech

**Sua biblioteca digital offline para Windows.** Organize livros, leia PDFs e EPUBs e aproveite mangás e HQs em CBZ, com opções de personalização e acesso ao Workshop Cliente.

## Baixar o VenusBiblio

**[⬇️ Baixar a versão estável mais recente](https://github.com/IGETech01/VenusBiblio-Updates/releases/latest)**

- **Versão disponível:** [v0.14.1](https://github.com/IGETech01/VenusBiblio-Updates/releases/tag/v0.14.1).
- **Sistema:** Windows.
- **Instalador direto:** [VenusBiblio_Setup_0.14.1.exe](https://github.com/IGETech01/VenusBiblio-Updates/releases/download/v0.14.1/VenusBiblio_Setup_0.14.1.exe).
- **Página oficial:** [Downloads IGETech](https://igetech01.github.io/VenusBiblio-Updates/).

## Principais recursos

- Leitura de **PDF, EPUB, mangás e histórias em quadrinhos (CBZ)**.
- Biblioteca offline com capas, organização e pesquisa.
- Ajustes de aparência e preferências de leitura.
- **Workshop Cliente** para os recursos disponibilizados aos leitores.
- Verificação de atualizações pelo GitHub nas versões compatíveis.

## Como instalar ou atualizar

1. Salve uma cópia de segurança dos seus livros e dados.
2. Feche o VenusBiblio.
3. Baixe o instalador da [versão estável mais recente](https://github.com/IGETech01/VenusBiblio-Updates/releases/latest) e execute-o.
4. Abra o aplicativo e confira seu acervo e suas preferências.

**Já usa uma versão com atualizador integrado?** Acesse **Atualizações → Verificar atualizações**. Se houver erro ou sua versão não tiver esse recurso, utilize o instalador oficial.

**Versões antigas, incluindo a linha v0.12.x, não possuem atualização integrada pelo GitHub.** Para elas, a atualização é manual. Consulte o [guia de migração](docs/MIGRACAO_VERSOES_ANTIGAS.md).

## Versões e segurança

A [v0.14.1](docs/releases/v0.14.1.md) é a versão estável atual; a [v0.14.0](docs/releases/v0.14.0.md) permanece disponível como versão anterior.
